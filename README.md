# Форсайт-сессия: сценарии развития территории и устойчивые решения

Учебная игра к семинару 8 октября 2026 г. по дисциплине «Современные системы целевого управления в РФ».
Четыре команды, у каждой своё устройство и свой вымышленный город. Ведущий следит за всеми со своего экрана.
Всё работает в локальной сети без интернета.

## Запуск

Требуется Node.js 20+ (проверено на 24) и Google Chrome (или Chromium от Playwright) для PDF.

```bash
cd ~/Desktop/sem
npm install            # один раз, нужен интернет
cp .env.example .env   # задайте ADMIN_PASSWORD
npm start              # сборка интерфейса + запуск сервера
```

Сервер печатает адреса:

```
Ведущий:  http://localhost:8080/admin
Команды:  http://192.168.1.10:8080/
```

Ноутбуки команд должны быть в той же сети Wi-Fi. Адрес и QR-код показаны на экране ведущего.
Если команды не открывают страницу, разрешите Node.js входящие соединения (macOS спросит при первом запуске; иначе: «Системные настройки → Сеть → Брандмауэр»).

| Команда | Что делает |
|---|---|
| `npm run data` | пересобирает `data/game_data.json` из `~/Desktop/Копия foresight_game_data.xlsx` (или `npm run data -- путь.xlsx`) |
| `npm start` | собирает интерфейс и запускает сервер |
| `npm run serve` | только сервер (интерфейс уже собран) |
| `npm run dev` | разработка: сервер с перезапуском + Vite на :5173 |
| `npm test` | unit-тесты движка (39) |
| `npm run e2e` | сквозной сценарий: ведущий и 4 команды проходят всю игру (67–70 проверок — часть зависит от выпавших джокеров, ≈ 40 с) |
| `npm run ui-smoke` | то же в настоящем браузере, со скриншотами в `out/ui/shots` |
| `npm run sim` | симуляция экономики (≈ 80 с) → `docs/ECONOMY_SIM.md` |

**.env:** `ADMIN_LOGIN`, `ADMIN_PASSWORD`, `PORT`. Состояние игры хранится в `data/game.sqlite` и переживает перезапуск сервера.

## Как поменять данные

1. Правите xlsx.
2. Выполняете `npm run data`. Скрипт проверит, что «Сейчас + Позже = Полная», что ссылки на меры существуют и что числа в правилах джокеров встречаются в тексте xlsx.
3. Перезапускаете сервер.

- Формальные правила джокеров лежат в `data/joker_rules.json`: в xlsx они записаны свободным текстом.
- Принятые правки правил лежат в `data/rules_overrides.json`: шаг штрафа 4, перенос штрафа, минимум 2 полные меры, возврат 80% при снятии, эффект снятой меры 50%. Когда внесёте их в xlsx, файл можно удалить.
- Трактовки описаны в `docs/RULES.md`, проверка экономики — в `docs/ECONOMY_REPORT.md`, ручной чек-лист — в `docs/TESTING.md`.

## Инструкция для ведущего (на 1 странице)

**До занятия (за 15 минут)**
1. Подключите ноутбук ведущего к той же Wi-Fi-сети, что и ноутбуки команд, и выполните `npm start`.
2. Откройте `http://localhost:8080/admin`, войдите и нажмите **«Создать игру»**.
3. Выведите вкладку «Вход команд» на проектор: на ней адрес, PIN и QR-код.
4. При необходимости поменяйте длительности шагов во вкладке «Настройки».

**Вход команд**
- Каждая команда открывает адрес и вводит PIN и название. Пятое устройство сервер не пустит.
- Участников (4–5 человек) можно вписать в лобби — это нужно для оценивания.

**Старт.** Нажмите «▶ Старт игры»: города раздаются случайно и без повторов.

**Объяснение правил (2 минуты)** — кратко показано у команд в лобби:
1. Город → тренды, драйверы, сигналы.
2. Две неопределённости → матрица 2×2 → 4 сценария.
3. 100 у.е. на меры. «Полная» — всё сейчас и полный эффект; минимум 2 меры должны быть полными. «Условная» — малая часть сейчас, остальное в конце, если сработает триггер. Без запуска условная мера даёт половину эффекта.
4. Два джокера: подготовленные меры удешевляют реакцию. После джокера меры можно переставить:
   - снятая полная мера возвращает 80% денег;
   - снятая условная освобождает от «Позже»;
   - у снятой меры эффект урезается (+2 → +1, +1 → 0);
   - меры, покрывшие негативный джокер, снять нельзя.
5. Закрытие: решаете, что запускать. Дефицит штрафуется: −1 балл за каждые 4 у.е.

**Во время игры** — вкладка «Обзор»:
- Видны: связь, город, шаг, таймер, резерв, прогноз на закрытии, последняя активность команды.
- Управление: пауза, +1 мин, пропустить шаг, открыть джокер — для всех сразу или для одной команды. Объявления выводятся на экраны команд.
- Кнопка «Подробнее» показывает всё, что ввела команда, а также уязвимости города и стартовые показатели (только для ведущего).
- Таймеры ведёт сервер. Когда время шага истекает, команда переходит дальше с тем, что успела ввести. Кнопкой «Готово» можно перейти раньше.

**Если что-то пошло не так**

| Ситуация | Что делать |
|---|---|
| Страницу команды обновили | Команда вернётся на своё место сама: токен хранится в браузере |
| Ноутбук команды сломался | Нажмите «Сброс устройства», затем команда входит с другого устройства по PIN и с тем же названием; прогресс сохраняется |
| Команда запуталась | «Сброс прогресса» — команда начинает заново с шага «Город» |
| Сервер упал | Снова выполните `npm start`: игра и таймеры восстановятся, потеря — несколько секунд |

**Итог и рефлексия**
- После «Защиты» у каждой команды появляется кнопка «Открыть PDF». Его показывает представитель команды.
- У ведущего во вкладке «Результаты» есть PDF каждой команды, ZIP со всеми PDF и CSV, JSON.
- Вопросы для обсуждения:
  - почему команды выбрали разные меры;
  - какой джокер сильнее всего повлиял на решения;
  - что дал индекс устойчивости;
  - чем форсайт отличается от прогноза.
- Вкладка «Оценивание»: таблица «участник × 5 критериев» (0–10), итог — среднее; выгружается в CSV для преподавателя.

## Устройство

- `engine/` — чистый модуль расчётов и общий протокол (TypeScript, без зависимостей). Его используют сервер, симуляция и клиент (только типы и проверки ввода).
- `server/` — Node.js + Fastify + Socket.IO + SQLite (better-sqlite3), PDF через Playwright.
  Почему Node, а не Python: один язык и один движок расчётов для сервера, симуляции и клиента — без дублирования правил.
- `web/` — React + Vite SPA: `/` — команды, `/admin` — ведущий. Шрифт PT Sans встроен в сборку, внешних CDN нет.
- Сервер — единственный источник правды. Клиент не получает:
  - уязвимости городов;
  - шесть показателей 1–10 и эффекты мер;
  - джокеры до их открытия (джокер вытягивается в момент открытия).
