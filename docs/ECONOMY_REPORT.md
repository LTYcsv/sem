# Проверка экономики игры

Источник: `data/game_data.json`, собранный из «Копия foresight_game_data.xlsx» + `data/rules_overrides.json`.
Расчёты выполняет чистый модуль `engine/src/engine.ts`, покрытый 34 тестами (`npm test`). Симуляция: `engine/sim/` (`npm run sim`).

Полные таблицы:
- [`ECONOMY_SIM.md`](ECONOMY_SIM.md) — **действующие правила** (шаг штрафа 4 у.е., перенос штрафа), 20 000 стратегий × 64 пары джокеров × 4 города = 5 120 000 партий;
- [`ECONOMY_SIM-before.md`](ECONOMY_SIM-before.md) — исходные правила xlsx (шаг 5, без переноса), тот же объём;
- [`ECONOMY_SIM-proposal.md`](ECONOMY_SIM-proposal.md), [`ECONOMY_SIM-p-measures.md`](ECONOMY_SIM-p-measures.md) — **не принятые** предложения по числам (5 000 стратегий на город).

**Метрика.** Δ = изменение суммы шести показателей (итог − старт). Для каждой стратегии берётся среднее по всем 64 парам «негативный × положительный джокер». Δ индекса города = Δ / 6. Δ сравнивается вместо итога, потому что города стартуют с разной суммы (26–38).

**Как устроена стратегия.** Портфель шага «Бюджет» задаёт для каждой меры режим «нет / полная / условная». Политика корректировок: докупать меры по своему порядку, пока резерв выше порога 0…30, или не докупать вообще. Политика положительного джокера: всегда / только бесплатные / никогда. Политика закрытия: не запускать / запускать, пока хватает резерва / запускать всё. Стратегия не знает джокеров заранее. Оптимум ищется локальным поиском из 20 стартовых точек.

## 2. Доминирующей стратегии нет

Перцентиль показывает место стратегии среди 20 000 случайных стратегий города; ожидаемая Δ указана при действующих правилах.

| Стратегия | Промград | Новая долина | Северный берег | Моноград | Отставание от лучшей, баллов |
|---|---|---|---|---|---|
| Всё условно, запуск по средствам | 13,6 (88%) | 11,6 (75%) | 13,6 (82%) | 13,6 (73%) | 2,8–3,8 |
| Всё условно, запуск всего в долг | −27 (0%) | −32 (0%) | −31 (0%) | −20 (0%) | 37–48 |
| Копить резерв | 2,0 (13%) | 2,0 (16%) | 2,0 (15%) | 2,0 (12%) | 13–15 |
| Только M13/M4/M2 | 12,3 (62%) | 9,3 (39%) | 11,1 (45%) | 12,3 (50%) | 4,2–6,2 |
| Жадный «баллы на 1 у.е.» (знает потолки города) | 14,4 (96%) | 13,8 (99%) | 15,4 (99%) | 15,7 (98%) | 1,6–2,1 |
| **Лучшая найденная** | **16,4** | **15,4** | **16,9** | **17,4** | 0 |

- Ни одна из трёх проверяемых стратегий («всё условно», «копить», «только дешёвые») не даёт максимум. Ни одна из них не бывает лучшей ни в одной из 64 пар джокеров (колонка «Пар на максимуме» = 0 в `ECONOMY_SIM.md`).
- До правки картина была другой. В Монограде «всё условно + запуск всего в долг» давала 22,0 и 99-й перцентиль. Лучшая стратегия Промграда уходила в долг в среднем на 127 у.е., Монограда — на 159 у.е. (`ECONOMY_SIM-before.md`). Подробности в п. 3.
- Лучшие стратегии разных городов отличаются составом. Общее у них: M4 полной, M13 условной, M2/M5/M6, широкий набор условных мер и запуск только по средствам. Перекрёстная проверка показывает, что лучшая стратегия одного города на другом городе теряет до 3,2 балла: стратегия Монограда на Новой долине даёт 12,2 против 15,4. Есть «хорошее семейство» (гибкий портфель с опционами), но нет одной стратегии, оптимальной везде. Для форсайт-игры это ожидаемый урок: решения, сохраняющие ценность в разных сценариях, выигрывают.
- Решения действительно влияют на результат. Между медианой случайных стратегий (10–12) и лучшей (15–17) около 5 баллов, это ≈ 0,9 пункта индекса города.

## 3. Штраф за дефицит невыгоднее вложения — после правки

Прирост на 1 у.е. считался по каталогу без учёта потолка 10.

| Вложение | Баллов на 1 у.е. |
|---|---|
| Лучшая полная мера: M2, M5 (4 балла / 20), M6 (4 / 18) | 0,20–0,22 |
| Лучший запуск на закрытии (полный − половинный эффект) / «Позже»: M6 3/13 | **0,23** |
| Типичный запуск (M2, M5 3/15; M7 4/22; M8, M12 3/19) | 0,16–0,20 |
| Бонус за резерв (до 20 у.е.) | 0,10 |

| Потеря на 1 у.е. дефицита | Исходные правила | Действующие |
|---|---|---|
| Номинально | 1/5 = 0,20 | 1/4 = **0,25** |
| Фактически, когда Экономика уже 1 | **0** (штраф упирается в нижнюю границу) | 0,25 (остаток переносится) |

Исходное правило не выполняло требование по двум причинам:
1. Номинальный штраф 0,20 ниже лучших запусков (0,23).
2. Главное: штраф снимается только с Экономики, а она не опускается ниже 1. После этого каждый дополнительный рубль долга бесплатен.

Симуляция это подтверждает. При исходных правилах запуск всего в долг выгоднее запуска «по средствам» в 21% пар стратегий в Промграде, 18% — в Северном береге и **69%** — в Монограде, где Экономика стартует с 4. Средний штраф, «съеденный» границей, — 2,6–2,8 балла на партию.

**Принятая правка (03.10.2026):** шаг штрафа 4 у.е. и перенос. Часть штрафа, которая не помещается в Экономику (она уже 1), снимается по одному баллу с наибольшего из остальных показателей. Записано в `data/rules_overrides.json`, в xlsx пока стоит 5.

| До → после | Промград | Новая долина | Северный берег | Моноград |
|---|---|---|---|---|
| Доля пар, где долг выгоднее | 21% → 6% | 6% → 2% | 18% → 2% | **69%** → 2% |
| Δ на 1 у.е. добровольного долга (медиана) | −0,02 → −0,15 | −0,05 → −0,18 | −0,02 → −0,18 | **+0,02** → −0,14 |
| Средний дефицит лучшей стратегии, у.е. | 127 → 0 | 0 → 0 | 0 → 0 | 159 → 0 |
| Лучшая Δ | 17,1 → 16,4 | 15,4 → 15,4 | 16,9 → 16,9 | 25,0 → 17,4 |

Оставшиеся 2–6% случаев, где долг даёт плюс, — это небольшой дефицит (несколько у.е.) при запуске M6 с её 0,23 балла на у.е. Это осознанный риск команды, а не стратегия.

## 4. Проигрышного города нет; Новая долина слабее всех на 1–2 балла

| Город | Сумма старт | Δ медиана случайных | Δ лучшая | Потеряно на потолке 10 (в среднем) |
|---|---|---|---|---|
| Промград | 33 | 11,6 | 16,4 | 2,9 |
| Новая долина | 38 | 10,1 | 15,4 | 4,4 |
| Северный берег | 37 | 11,6 | 16,9 | 2,7 |
| Моноград | 26 | 12,3 | 17,4 | 1,1 |

Разброс лучших Δ между городами — 2,0 балла (0,33 пункта индекса). Это меньше, чем разница между средней и сильной командой внутри одного города (около 5). Новая долина отстаёт из-за потолка: Адаптивность 8 и Человеческий капитал 8 быстро упираются в 10.

**Предложение (не применено):** Новая долина — Адаптивность 8 → 7, Человеческий капитал 8 → 7. Результат: лучшая Δ 15,6 → 16,5 (в сочетании с правками мер из п. 5), медиана 10,5 → 11,7. Разброс лучших между городами сокращается с 2,3 до 1,4 (`ECONOMY_SIM-proposal.md`). Если не менять ничего, в PDF и так показываются «было → стало» и Δ, поэтому обсуждение честное.

## 5. Вклад мер и джокеров

Коэффициент регрессии — средний прирост ожидаемой Δ от включения меры в режиме «полная» при прочих равных. Полная таблица в `ECONOMY_SIM.md`, п. 5.

| Мера | Полная (Пр / НД / СБ / Мг) | Частота в топ-1% | Вывод |
|---|---|---|---|
| M13 Сине-зелёная инфраструктура | +1,6 / +1,4 / +1,2 / +1,2; условная — единственная с плюсом во всех городах | **79%** | Самая частая в лучших портфелях: дёшева, 4 джокера (J-1, J-8, J+2, J+7). Не «всегда лучшая», но близко к этому |
| M2, M5, M6 | +1,1…+1,9 | 65–68% | Сильные, эффективность ≈ 0,2 балла на у.е. **M6 сильна без единого джокера** — за счёт эффекта 4 балла / 18 у.е. |
| M4 | +0,4…+1,1 | 71% | Дешёвая (15), защищает от J-2 |
| M7, M8, M9, M14, M15, M10, M12 | +0,4…+2,0 | 40–53% | Рабочие, зависят от города |
| M1 Модернизация сетей | −0,7…+0,5 | 37% | Окупается слабо |

| **M11 Новый жилой район** | **−1,1…−1,3 во всех городах** | 39%* | **Никогда не окупается**: 3 балла за 35 у.е. (0,09 на у.е.), условная — 2 балла половины эффекта, запуск даёт +1 за 25 у.е. Не участвует ни в одном джокере |

**Предложение по мерам (не применено), `ECONOMY_SIM-p-measures.md`:**

| Правка | Коэффициент «полная» до → после (Пр / НД / СБ / Мг) |
|---|---|
| M11: цена 35 → 30 (8 + 22), Инфраструктура −1 → 0 | −1,26 / −1,07 / −1,16 / −1,19 → −0,21 / +0,44 / +0,15 / +0,39 |

Инварианты при этом сохраняются: 0 нарушений, а долг остаётся невыгодным (2–7% пар).

**Джокеры.** Средняя Δ случайных стратегий при выпадении джокера:
- Самый тяжёлый негативный — J-4 «Закрытие работодателя» (30 у.е.): −0,8…−1,3 к средней Δ относительно самого мягкого J-8.
- Положительные: лучшие J+7 и J+2 (+0,7…+1,5 к J0).
- J+1 «Инвестор» и J+6 «Туристический бум» дают **меньше, чем J0**, если их использовать без своей меры. Пример: J+1 без M7 — 20 у.е. за +2 балла, то есть 0,10 на у.е., хуже почти любого вложения. Это не ошибка, а настоящий выбор «использовать / пропустить». Расчёт на экране показывает команде цену и бонус. Если хотите, чтобы эти джокеры были однозначно полезны, поднимите бонус J+1 до 3 или снизьте цену без M7 до 15.
- M13 участвует в 4 джокерах, M6 и M11 — ни в одном. M6 это не вредит, M11 вредит (см. выше).
