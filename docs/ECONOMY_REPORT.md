# Проверка экономики игры

Расчёты выполняет чистый модуль `engine/src/engine.ts` (40 тестов, `npm test`). Симуляция — `engine/sim/` (`npm run sim`).

**Метрика Δ** — изменение суммы шести показателей (итог − старт), среднее по всем 64 парам «негативный × положительный джокер». Δ индекса города = Δ / 6. Сравнивается Δ, а не итог: города стартуют с разной суммы показателей (26–37).

**Стратегия** задаётся пятью решениями:
- портфель шага «Бюджет» (с правилом «минимум 2 полные»);
- снятие мер после джокера: не снимать / снимать полные при дефиците / снимать все незаблокированные полные;
- докупка мер в корректировках;
- решение по положительному джокеру;
- политика закрытия: не запускать / запускать по средствам / запускать всё в долг.

Джокеров стратегия заранее не знает. Оптимум ищется локальным поиском из 20 стартовых точек.

## 2. Доминирующая стратегия

Ожидаемая Δ и перцентиль среди 20 000 случайных стратегий города, правила v3.

| Стратегия | Промград | Новая долина | Северный берег | Моноград |
|---|---|---|---|---|
| Две полные (M4, M6) + всё условно, запуск по средствам | 14,8 (97%) | 14,9 (98%) | 14,9 (97%) | 14,9 (92%) |
| То же, запуск всего в долг | −22,8 (0%) | −24,8 (0%) | −24,8 (0%) | −17,8 (0%) |
| Копить: только две дешёвые полные | 9,0 (16%) | 8,0 (16%) | 9,0 (18%) | 9,0 (14%) |
| Только M13/M4/M2 | 12,3 (60%) | 10,3 (28%) | 11,1 (36%) | 12,3 (44%) |
| Жадный «баллы на 1 у.е.» | 14,4 (95%) | 13,3 (84%) | 15,4 (99%) | 15,7 (97%) |
| «Всё полным → после джокера снять незадействованные» | 14,3 (95%) | 14,6 (97%) | 16,1 (100%) | 15,9 (98%) |
| **Лучшая найденная** | **17,8** | **17,3** | **18,0** | **19,1** |

- Простые стратегии максимум не дают. «Всё условно», «копить» и «только дешёвые» отстают от лучшей на 2,4–10,1 балла и ни в одной из 64 пар джокеров не равны лучшей случайной.
- **⚠ Возврат 80% создаёт общий приём.** Во всех четырёх городах лучшая стратегия покупает несколько мер полными, а после негативного джокера снимает все, что его не покрыли.
- Почему так выходит: снятая полная мера даёт такой же урезанный эффект, как подготовленная условная, но обходится дешевле — 20% цены против 25–33% «Сейчас». Например, M2: 4 у.е. против 5; M7: 6 против 8.
- Случайным стратегиям такое снятие в среднем вредит (коэффициент −1,0…−1,4). Значит, это приём для «знающих», но рациональная команда к нему придёт.

| Возврат при снятии полной меры | Политика снятия у лучшей стратегии (Пр / НД / СБ / Мг) | Лучшая Δ |
|---|---|---|
| 80% (действует) | снимать всё / всё / всё / всё | 17,8 / 17,3 / 18,0 / 19,1 |
| **60% (предложение)** | всё / всё / не снимать / не снимать | 16,8 / 16,6 / 17,0 / 17,9 |

**Предложение (не применено): возврат 60%.** Тогда снятие перестаёт быть универсальным приёмом, и лучшая политика начинает зависеть от города. Это одна строка `"fullRefundShare": 0.6` в `data/rules_overrides.json`.

## 4. Проигрышного города нет

| Город | Сумма старт | Δ: медиана случайных | Δ: лучшая (v2 → v3) | Теряется на потолке 10 (v3) |
|---|---|---|---|---|
| Промград | 33 | 11,9 | 17,6 → 17,8 | 1,9 |
| Новая долина | 38 → **36** | 11,6 | 16,5 → **17,3** | 2,2 |
| Северный берег | 37 | 11,9 | 17,9 → 18,0 | 1,7 |
| Моноград | 26 | 12,6 | 19,1 → 19,1 | 0,7 |

- Разброс лучших Δ между городами сократился с 2,6 до **1,8 балла** (0,3 пункта индекса). Это меньше, чем разница между медианной и лучшей стратегией внутри города (около 6 баллов).
- Новая долина больше не отстаёт по медиане (11,6 против 11,9–12,6).
- Моноград остаётся немного впереди по лучшему результату: у него самая низкая стартовая сумма, а значит, больше пространства до потолка.

## 5. Вклад мер и джокеров (v3)

Коэффициент регрессии — прирост ожидаемой Δ от включения меры полной на шаге «Бюджет».

| Мера | Коэффициент (Пр / НД / СБ / Мг) | В топ-1% | Вывод |
|---|---|---|---|
| M4 | +1,1 / +0,6 / +0,8 / +0,9 | **85%** | Самая частая: самая дешёвая полная (15) и защищает от J-2 |
| M13 | +1,1 / +1,1 / +0,9 / +1,0 | 47% | Сильная, участвует в 4 джокерах |
| M2, M5, M6, M7, M9, M15 | +0,8…+1,7 | 24–44% | Рабочие; **M6 сильна без единого джокера** |
| M8, M12, M14 | +0,5…+1,3 | 27–32% | Зависят от города |
| **M11** (после правки) | **+0,6 / +0,6 / +0,7 / +0,7** (было −0,1…−0,2) | 35% | Теперь окупается во всех городах |
| **M16** (после правки) | **+0,7 / +0,8 / +0,5 / +0,4** (было −0,1…+0,5) | 19% | Окупается |
| **M1** (после правки) | **+0,8 / +0,9 / +0,7 / +0,4** (было −0,1…+0,6) | 25% | Окупается |
| M3, M10 | +0,1…+0,7 | 30–38% | Самые слабые, но в плюсе во всех городах |

Мер, которые не окупаются, больше нет: все 16 коэффициентов положительные во всех городах.

Джокеры — средняя Δ случайных стратегий при выпадении джокера:
- J-4 тяжелее всех (30 у.е.): на 0,9–1,3 балла ниже J-8.
- J+2 и J+7 лучшие: выше J0 на 0,4–1,8 балла.
- J+1 и J+6 без своей меры дают примерно как J0 (±0,3). Это оставлено как осознанный выбор «использовать / пропустить».
