# Проверка экономики игры

Все расчёты делает модуль `engine/src/engine.ts`. Он не зависит от сервера и покрыт 40 тестами (`npm test`). Симуляция лежит в `engine/sim/` и запускается командой `npm run sim`.

**Метрика Δ** — насколько изменилась сумма шести показателей города (итог минус старт). Берётся среднее по всем 64 парам «негативный × положительный джокер».
- Δ индекса города = Δ / 6.
- Сравниваем изменение, а не итог: города стартуют с разной суммы показателей (от 26 до 37).

**Из чего состоит стратегия**
- портфель на шаге «Бюджет», с учётом правила «минимум 2 полные»;
- снятие мер после джокера: не снимать / снимать полные при дефиците / снимать все незаблокированные полные;
- докупка мер в корректировках;
- решение по положительному джокеру;
- закрытие: не запускать / запускать по средствам / запускать всё в долг.

Стратегия не знает заранее, какие джокеры выпадут. Лучшая стратегия ищется локальным поиском из 20 стартовых точек.

## 2. Нет стратегии, которая выигрывает всегда — выполнено

Ожидаемая Δ и перцентиль среди 20 000 случайных стратегий того же города, правила v4.

| Стратегия | Промград | Новая долина | Северный берег | Моноград |
|---|---|---|---|---|
| Две полные (M4, M6), остальное условно, запуск по средствам | 14,8 (99%) | 14,9 (100%) | 14,9 (99%) | 14,9 (97%) |
| То же, но запуск всего в долг | −22,8 (0%) | −24,8 (0%) | −24,8 (0%) | −17,8 (0%) |
| Копить: только две дешёвые полные | 9,0 (17%) | 8,0 (16%) | 9,0 (19%) | 9,0 (15%) |
| Только M13, M4, M2 полными | 12,3 (70%) | 10,3 (32%) | 11,1 (42%) | 12,3 (54%) |
| Жадная: максимум баллов на 1 у.е. | 14,4 (99%) | 13,3 (92%) | 15,4 (100%) | 15,7 (99%) |
| Всё полным, после джокера снять незадействованное | 13,0 (85%) | 13,3 (92%) | 13,5 (90%) | 13,1 (73%) |
| **Лучшая найденная** | **16,8** | **16,5** | **17,2** | **17,8** |

- **Возврат 60% закрыл лазейку.** При 80% все четыре лучшие стратегии делали одно и то же: покупали меры полными, а после джокера снимали всё незаблокированное. При 60% такой приём проигрывает лучшей стратегии 3,3–4,7 балла. Лучшие стратегии теперь снимают меры только при дефиците (Промград, Новая долина, Моноград) или не снимают вовсе (Северный берег). Снятие стало страховкой, а не способом сэкономить.
- Если снимать всё незаблокированное, результат в среднем падает на 1,8 балла. Если снимать только при дефиците, он немного растёт (+0,1…+0,2).
- «Две полные + остальное условно» и жадная стратегия — сильные (92–100% перцентиля), но до лучшего результата им не хватает 1,3–2,9 балла.
- Ни одна стратегия из таблицы не лучшая во всех 64 парах джокеров: в лучшем случае она лучшая в 3 парах из 64.
- Лучшая стратегия одного города, применённая в другом, теряет до 3,1 балла. Хорошие портфели похожи (M4, M6, M13 и широкий набор условных мер), но универсального нет.

| Возврат при снятии полной меры | Как лучшая стратегия снимает меры (Пр / НД / СБ / Мг) | Лучшая Δ (Пр / НД / СБ / Мг) |
|---|---|---|
| 80% (v3) | всё / всё / всё / всё | 17,8 / 17,3 / 18,0 / 19,1 |
| **60% (v4)** | при дефиците / при дефиците / не снимает / при дефиците | 16,8 / 16,5 / 17,2 / 17,8 |

## 3. Уходить в долг невыгодно — выполнено

Что приносит 1 у.е.:

| Вложение | Баллов на 1 у.е. |
|---|---|
| Лучшая полная мера (M2 и M5: 4 балла за 20 у.е.; M6: 4 за 18) | 0,20–0,22 |
| Лучший запуск условной меры на закрытии (M6: 3 балла за 13 у.е.) | 0,23 |
| Бонус за остаток резерва | 0,10 |

Что стоит 1 у.е. дефицита:

| | v0 (xlsx) | v1–v4 |
|---|---|---|
| По правилу | 0,20 балла | **0,25 балла** |
| Если Экономика уже упала до 1 | **0** — штраф просто не списывается | 0,25 — остаток переносится на другие показатели |

Сравнение одной и той же стратегии: «запустить всё в долг» против «запускать только по средствам».

| | Промград | Новая долина | Северный берег | Моноград |
|---|---|---|---|---|
| Доля пар джокеров, где долг выгоднее: v0 → v4 | 28% → 9% | 13% → 4% | 30% → 4% | **75%** → 4% |
| Сколько даёт 1 у.е. долга (медиана): v0 → v4 | −0,02 → −0,12 | −0,04 → −0,14 | −0,02 → −0,15 | **+0,03** → −0,11 |
| Средний дефицит лучшей стратегии, у.е.: v0 → v4 | 127 → 0 | 0 → 0 | 0 → 0 | 159 → 0 |

## 4. Нет заведомо проигрышного города — выполнено

| Город | Сумма на старте | Δ: медиана случайных стратегий | Δ: лучшая (v2 → v3 → v4) | Теряется на потолке 10 |
|---|---|---|---|---|
| Промград | 33 | 11,5 | 17,6 → 17,8 → 16,8 | 1,7 |
| Новая долина | 36 | 11,3 | 16,5 → 17,3 → 16,5 | 1,9 |
| Северный берег | 37 | 11,6 | 17,9 → 18,0 → 17,2 | 1,4 |
| Моноград | 26 | 12,1 | 19,1 → 19,1 → 17,8 | 0,5 |

- Лучшие результаты городов отличаются не больше чем на **1,3 балла** (0,2 пункта индекса). В v2 было 2,6. Для сравнения: внутри одного города сильная стратегия обгоняет медианную примерно на 5,5 балла.
- Медианы городов отличаются не больше чем на 0,9 балла.

## 5. Вклад мер и джокеров (v4)

Коэффициент показывает, на сколько в среднем растёт Δ, если включить меру полной на шаге «Бюджет».

| Мера | Коэффициент (Пр / НД / СБ / Мг) | В лучшем 1% стратегий | Вывод |
|---|---|---|---|
| M4 | +1,0 / +0,6 / +0,7 / +0,8 | **70%** | Чаще всех: самая дешёвая полная мера (15 у.е.), защищает от J-2 |
| M2, M5, M6, M13 | +0,6…+1,2 | 54–58% | Ядро сильных портфелей. M6 сильна, хотя не участвует ни в одном джокере |
| M7, M9, M14, M15 | +0,6…+1,5 | 22–34% | Рабочие, выгода зависит от города |
| M8, M10, M11, M12 | +0,1…+1,1 | 26–36% | Выгода сильно зависит от города |
| M1, M16 | +0,1…+0,7 | 13–19% | Слабые, но в плюсе во всех городах |
| **M3** | +0,5 / +0,5 / +0,2 / **−0,1** | 26% | В Монограде на грани окупаемости: паводок там не главный риск |

Все меры, кроме M3 в Монограде (−0,1), окупаются во всех городах. Раньше M11 не окупалась ни в одном.

Как джокеры влияют на среднюю Δ случайных стратегий:
- J-4 самый тяжёлый (30 у.е.): с ним Δ на 1,0–1,4 балла ниже, чем с самым мягким J-8.
- J+2 и J+7 самые полезные: на 0,4–1,8 балла выше нейтрального J0.
- J+1 и J+6 без своей меры дают примерно столько же, сколько J0 (±0,3). Использовать их или пропустить — настоящий выбор.
