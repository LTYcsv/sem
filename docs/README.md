# Документы

## Для жюри и ведущих — `jury/`

Командам не показывать. Печатать можно по одному файлу на город.

| Файл | Что внутри |
|---|---|
| [`jury/0-kak-otsenivat.md`](jury/0-kak-otsenivat.md) | Как оценивать: из чего складывается оценка, как считается оценка 1–10 в PDF, сравнение городов, сильный и слабый ответ, меры против джокеров, вопросы на защите |
| [`jury/1-promgrad.md`](jury/1-promgrad.md) | Промград: старт, ожидаемые ответы, лучшие портфели, какой рост какую оценку даёт, на что смотреть |
| [`jury/2-novaya-dolina.md`](jury/2-novaya-dolina.md) | Новая долина — то же |
| [`jury/3-severny-bereg.md`](jury/3-severny-bereg.md) | Северный берег — то же |
| [`jury/4-monograd.md`](jury/4-monograd.md) | Моноград — то же |

Таблицы «Оценка за результат» в файлах городов генерируются командой `npm run jury` (она же запускается после `npm run benchmarks`). Остальной текст правится вручную.

## Правила — `RULES.md`
