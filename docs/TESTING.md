## Ручной чек-лист перед семинаром (≈ 20 минут, 2 ноутбука + телефон)

Отмечайте ✓. Каждый пункт: действие → наблюдаемый результат.

**Сеть и запуск**
- [ ] `npm start` на ноутбуке ведущего → в консоли адрес `http://192.168.x.x:8080/`.
- [ ] Со второго ноутбука в той же Wi-Fi-сети открыть этот адрес → страница входа «Форсайт-сессия». Если не открывается — брандмауэр (см. README).
- [ ] Выключить интернет на обоих ноутбуках (оставить Wi-Fi-сеть) → обе страницы работают, шрифт тот же (PT Sans).

**Вход**
- [ ] `/admin`, неверный пароль → «Неверный логин или пароль».
- [ ] «Создать игру» → крупный PIN из 6 цифр и QR-код.
- [ ] Отсканировать QR телефоном → открывается вход с уже подставленным PIN.
- [ ] Войти 4 командами (вкладки в режиме инкогнито или разные браузеры) → 4 зелёные плитки в лобби ведущего.
- [ ] Пятая команда → «В игре уже 4 команды — мест нет».
- [ ] Обновить страницу команды (F5) → команда остаётся в лобби, без повторного входа.

**Игра (одна команда проходит всё, остальные — «Пропустить шаг» у ведущего)**
- [ ] Старт → у команд разные города, бейдж «УЧЕБНЫЕ ДАННЫЕ»; на карточке нет уязвимостей и шкалы 1–10.
- [ ] Ввести 2 тренда, обновить страницу через 2 с → тренды на месте.
- [ ] Сценарий из двух предложений → счётчик «2 из 3» красный, синяя подсказка «Не заполнено», «Готово» активна.
- [ ] Бюджет: выбрать мер больше чем на 100 у.е. → сообщение «нельзя потратить больше 100».
- [ ] Условная мера без триггера → в подсказках «нужен триггер», «Готово» активна.
- [ ] Панель баланса: старт / потрачено / резерв / «Позже» / прогноз. При минусе прогноз красный, рядом подпись о штрафе.
- [ ] Время бюджета истекло → карта джокера сама переворачивается, расчёт вида «25 → 8 у.е. из-за M3», резерв уменьшился.
- [ ] Бюджет с одной полной мерой → «Нужно минимум 2 полные меры», «Готово» неактивна.
- [ ] Корректировка: «Снять меру» у полной → в подтверждении «Вернётся N у.е. (60%)», резерв растёт на N. У условной → «Сейчас» не вернётся, «Позже» исчезает из обязательств.
- [ ] Мера, удешевившая негативный джокер, помечена «🔒 покрыла джокер», кнопки «Снять» у неё нет.
- [ ] Положительный джокер: показаны цена, резерв после, «что получите»; при нехватке денег — «Недоступно».
- [ ] Закрытие: по каждой условной мере «Запускаем / Не запускаем» + обоснование; итоговый баланс и дефицит меняются сразу.
- [ ] Защита → «Открыть PDF»: русский текст читается, есть график «было → стало», индекс города, индекс устойчивости, журнал.

**Ведущий**
- [ ] «Пауза всем» → у команд значок ⏸, таймер стоит. «Продолжить» → идёт дальше.
- [ ] «+1 минута» одной команде → у неё таймер +60 с, у других без изменений.
- [ ] Объявление → жёлтая полоса на экранах команд.
- [ ] «Подробнее» → видны все ответы команды, уязвимости города и стартовые показатели.
- [ ] Перезапустить сервер (Ctrl+C, `npm run serve`) посреди шага → команды переподключились сами, шаг и время сохранились (потеря ≤ 5 с).
- [ ] «Сброс устройства» → у команды экран входа; вход тем же названием → прогресс на месте.
- [ ] «Результаты» → ZIP скачивается, внутри PDF всех команд, `results.csv` и `grades.csv` открываются в Excel с кириллицей.
- [ ] «Оценивание» → ввести 9 и 8 → итог 8,5; значение 11 не принимается.

**Проектор**
- [ ] Экран ведущего (PIN/QR) и PDF команды на проекторе читаются с последнего ряда.
